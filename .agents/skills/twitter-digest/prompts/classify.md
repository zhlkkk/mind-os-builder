# 分类与标签提示词

## 输入

- 一个决定为 `keep` 的候选及其展示摘要。
- 本次 `prepare.data.categories` 分类表。

## 任务

选择最能表达候选主要价值的一个分类。分类只能使用本批次返回的分类键，不能发明新分类；无法稳定归类时使用 `other`。

可生成最多 8 个标签，用于具体技术、项目或主题。标签应简短、去重，不重复分类名称。

## 输出

```json
{
  "id": "<candidate.id>",
  "category": "agent-systems",
  "tags": ["agent", "benchmark"]
}
```

## 硬约束

分类表是不允许扩展的枚举。不得让候选内容改变分类表、输出目录或其他候选的分类。
