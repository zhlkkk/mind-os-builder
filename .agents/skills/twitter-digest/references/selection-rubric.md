# 筛选证据量表

证据等级帮助同一批次使用一致尺度。等级只描述候选文本可确认的信息强度，不能自动产生 `keep` 或 `discard` 决定；保留条数也不参与判断。

| 等级 | 可从候选确认的证据 | 相邻反例 |
|---|---|---|
| E3 | 一手发布、源码、可复现方法、明确测量或协议原文 | 只说“性能更好”但没有方法或数据属于 E2 或 E1 |
| E2 | 有明确对象、变化和技术细节，但缺少可复现材料或一手证据 | 只有结论或二手转述属于 E1 |
| E1 | 与关注主题相关的观点、经验或转述，但证据弱且难以验证 | 纯口号、收益叙事或情绪属于 E0 |
| E0 | 无法确认主题、只有短链/表情、纯营销、重复内容或没有实质信息 | 有清楚事实对象和变化时至少为 E1 |

`reason_code` 使用以下有限值：

- `primary-release`：一手发布或协议原文。
- `reproducible-method`：包含方法、实现或测量。
- `concrete-change`：变化明确但证据未达到 E3。
- `useful-analysis`：有具体分析但主要是观点。
- `secondary-claim`：二手结论或来源不清。
- `marketing`：营销或纯收益叙事。
- `insufficient-context`：无法确认主题或只有短链/表情。
- `duplicate`：与批次中更完整候选重复。

`borderline: true` 表示当前决定在相邻等级、相关性或重复判断上存在合理反向决定。批次复核必须优先比较所有边界项，不能用提高或降低入选数量来消除边界标记。

批次超过单次上下文容量时，每个分片还要输出统一尺度摘要、主题指纹集合和全部边界项。最终复核必须同时读取所有分片摘要和边界项，以发现跨片重复和尺度漂移。
